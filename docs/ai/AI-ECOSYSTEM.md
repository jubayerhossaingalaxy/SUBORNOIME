# AI Engineering Ecosystem

SUBORNO uses lightweight repository-native AI customization:

- Copilot repository instructions for shared rules.
- Path instructions for C++, Windows, tests and documentation.
- Read-only custom agents for specialized review roles.
- Project Skills for reusable engineering workflows.
- Microsoft Learn MCP for official documentation lookup.
- Existing VS Code CMake Tools, clangd and GitHub Actions.

No local LLM, GPU service, Docker stack or vector database is required.

The portable Engine remains independent of AI tooling, COM, TSF and Windows.
