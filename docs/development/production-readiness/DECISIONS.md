# SUBORNO Production Readiness Decisions

## Accepted repository decisions

- C++20 shared engine.
- MSVC v143/VS 2022 x64 Windows production.
- Ubuntu Clang/GCC portability.
- ICU and SQLite dependencies.
- TSF/COM native Windows integration.
- No custom desktop UI.
- MIT and clean-room constraints.

## Approval-required decisions

- COM apartment model.
- Candidate key mapping.
- Dictionary source and license.
- User-learning default.
- Settings storage format/location.
- Per-user versus per-machine registration.
- MSI versus MSIX.
- Windows minimum build.
- Performance thresholds.
- Signing certificate ownership.
