# AI Testing and Evaluation

Verification must cover:

- Copilot instruction discovery in a fresh chat.
- Custom agent discovery and tool scope.
- Skills discovery and lock restoration.
- Microsoft Learn MCP read-only tool call.
- Agent-generated test recommendations against real acceptance criteria.
- Documentation/source drift.
- Existing parser, session, Unicode and candidate tests.
- Future COM/TSF lifecycle, edit sessions and host compatibility.

No PASS status is assigned until the command or workflow is executed.
Interactive Windows application support is not inferred from hosted CI.
